# Utilizando-as-Ferramentas-do-Github-para-Solucionar-Algoritmos-em-Python


Descrição
Este projeto foi desenvolvido com o objetivo de explorar como as ferramentas do GitHub podem ser aplicadas para resolver desafios de algoritmos em Python. Através deste repositório, foi possível trabalhar com diferentes tipos de algoritmos e problemas computacionais, ao mesmo tempo que se aprende a gerenciar versões, realizar colaborações e otimizar o fluxo de trabalho usando Git e GitHub.

Tecnologias Utilizadas
Python: Linguagem de programação utilizada para resolver os algoritmos.

Git: Ferramenta de controle de versão para gerenciar o código.

GitHub: Plataforma utilizada para hospedar o repositório e colaborar com outros desenvolvedores.

GitHub Actions (se aplicável): Utilizado para automação de testes e integração contínua (CI).

Algoritmos Resolvidos
Este repositório contém soluções para diferentes tipos de algoritmos, incluindo:

Algoritmos de busca (por exemplo, busca binária)

Algoritmos de ordenação (por exemplo, quicksort, mergesort)

Problemas clássicos de programação (por exemplo, Fibonacci, Fatorial)

Algoritmos de grafos (por exemplo, BFS, DFS)
